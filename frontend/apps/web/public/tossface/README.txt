토스페이스(Tossface) — 카테고리 픽토그램 원본
https://github.com/toss/tossface  ·  https://toss.im/tossface

이 디렉터리의 SVG 는 토스팀이 배포하는 원본 파일을 그대로 가져온 것이다(파일명은 유니코드
코드포인트). 수정하지 않는다 — 라이선스가 변형·각색으로 만든 2차적저작물을 금지한다.
새 픽토그램이 필요하면 위 저장소의 dist/svg 에서 같은 방식으로 받아 넣는다.

웹폰트(woff2) 대신 SVG 를 쓰는 이유: 토스페이스는 컬러 이모지 폰트라 유니코드 구간별로 쪼갠
서브셋 하나가 0.5~1.9MB 다. 홈에서 쓰는 픽토그램 8개는 6개 서브셋에 흩어져 있어 폰트로 받으면
약 5.9MB 를 내려받게 되는데, 같은 그림을 원본 SVG 로 받으면 합계 9KB 다.
CSP 의 font-src 가 'self' 로 묶여 있어 CDN 폰트도 정책 완화 없이는 쓸 수 없다.

재배포 조건에 따라 라이선스 전문(LICENSE.txt)을 함께 둔다.
출처 표시는 서비스 푸터에 노출한다.
