# 시설 예약 월↔주 뷰 아키텍처 전환 설계 (2026-07-17)

Google Calendar 방식으로 역할을 분리한다 — **월간 = 날짜 탐색, 주간 = 실제 시간 선택·신청**.
현행 "월간 + 사이드 패널(일간/주간 토글)" 구조를 "본문 월↔주 전환 + 주간 전용 사이드바"로 바꾼다.
기존 디자인 시스템(컬러·컴포넌트·타이포)은 유지하고 배치·플로우만 바꾼다(사용자 요구 §10).
목업: Concept A `FacWeek`/`FacViewToggle`/`FacSlotPanel`(F3) — 단 토글은 목업의 [일][주]가 아니라
사용자 지시대로 **[월][주]**.

## 1. 뷰 상태 머신

- 페이지 상태 `calendarView: 'month' | 'week'`, 기본 `'month'`.
- **월간에서 날짜 탭 → `selectedDate` 설정 + `'week'` 자동 전환**(핵심 플로우).
- 헤더 [월] 탭 → `'month'` 복귀 — `selectedDate`·`selection`은 **유지**(월간 셀 강조 유지,
  다시 [주] 탭하면 그 주로 돌아옴 — Google Calendar 동작).
- [주] 탭(선택일 없음) → 기준일 = 오늘이 창 내면 오늘, 아니면 `bookableFrom`. 그 날을
  `selectedDate`로 설정(주간은 항상 선택일이 있다 — 사이드바가 선택일 기준이므로).
- 딥링크 `?date=` 존재 시 초기 뷰 = `'week'`(기존 date 파싱·창 밖 정리 이펙트 유지).
- URL에는 view 를 쓰지 않는다(기존 replaceState 관례 — facilityId·date만).

## 2. 캘린더 헤더 (뷰 전환의 단일 진입점)

캘린더 카드 상단에 공용 헤더를 둔다(목업 F3 헤더 구성):

```
[월 | 주]  |  ←  {기간 라벨}  →        (우측) 범례
```

- **[월 | 주] 토글**: 목업 `FacViewToggle` 시각(회색 트레이 + 활성 흰 배경·그림자) — 두잉 토큰으로
  `bg-graysoft rounded-[10px] p-[3px]` + 활성 `bg-paper shadow-sm text-ink-deep`. 세그먼트는
  `role="tablist"` 유지(기존 패널 토글의 접근성 패턴 이식).
- 기간 라벨: 월간 = "2026년 7월"(기존), 주간 = **"7월 20일 – 26일"**(주 시작~끝, 월 경계를 넘으면
  "7월 28일 – 8월 3일"처럼 뒤쪽에 월 표기).
- 이동 화살표: 월간 = 기존 당월⇄익월 캡. 주간 = **주 단위 이동**, 캡은 `bookableFrom`이 속한 주 ~
  `bookableUntil`이 속한 주(범위 밖 비활성).
- 범례: 월간 = 기존(여유/보통/혼잡/마감), 주간 = 가능/예약됨/대기(목업 F3 — sage-mist/graysoft/warm 계열).
- 기존 BookingCalendar 헤더(타이틀+화살표+범례)는 이 공용 헤더로 흡수(월간 시 동일 정보 유지 —
  창 칩(현재/다음 예약 가능) 행도 월간에서 유지).

## 3. 월간 뷰 (탐색 전용)

- 기존 BookingCalendar 그대로(카드형 셀·히트맵·기간 외·오픈 마커·오늘 도트).
- 유일한 변화: **날짜 탭이 패널을 여는 대신 주간 뷰로 전환**한다. 월간 옆 사이드 패널 없음 —
  캘린더가 본문 전체 폭.
- 시간 선택 UI 없음(사용자 요구 §3).

## 4. 주간 뷰 (시간 선택의 장) — WeekTimetable 전면 개편 (목업 F3)

- 그리드: 좌측 시간 라벨 열(`48px`, `HH:00` mono) + 7일 컬럼(월~일), 행 높이 40px(모바일 36px).
  가로 스크롤 허용(기존 overflow-x-auto min-width 유지).
- 요일 헤더: 요일 + 날짜 숫자(원형). **선택일은 요일에 "· 선택" 접미 + 숫자 ink 원형 반전**(목업).
- **선택일 컬럼 강조**(목업): 컬럼 배경 `bg-sage/20` 계열 tint + ink 프레임(상단 헤더부터 마지막
  행까지 좌우 보더, 마지막 행 하단 라운드).
- 셀 상태색(SLOT_STYLE ↔ 두잉 토큰): 가능=`bg-sage-mist border-sage-soft`, 예약됨=`bg-graysoft
  border-line`, 대기=`bg-warm/15 border-warm/60` + 셀 내 소형 라벨 "대기"(목업 — 이름은 셀에 넣지
  않는다, 사이드바가 담당), 지난=`bg-graysoft/40`, 선택=`bg-ink + ✓`(sage 보더·그림자, 목업).
- **셀 탭 = 시간 선택**(§9.5 이연분을 여기서 구현):
  - 선택일 컬럼의 가능/대기 셀 탭 → `toggleSlotSelection`(기존 규칙 그대로 — 확장·재탭 해제).
  - **다른 요일**의 가능/대기 셀 탭 → 그 날짜로 `selectedDate` 전환 + 해당 슬롯 단일 선택
    (Google Calendar 자연 동작 — 날짜를 다시 고르러 월간에 갈 필요 없음).
  - 차단·지난·데이터 없음·창 밖 셀은 비활성(기존 게이팅 유지).
- 요일 헤더 탭 → 그 날짜 선택(기존 동작 유지, 창 밖·데이터 밖 비활성).
- 주간 표시 주가 바뀌어 월 경계를 넘으면 **주의 월요일이 속한 월**을 조회 월로 스위칭
  (yearMonthOverride 연동 — availability 는 당월·익월만 허용하므로 그 캡 안에서만 이동 가능).
  주가 두 달에 걸치면 조회 월 밖 요일은 데이터 없음 → 비활성(기존 동작 수용·명시).

## 5. 사이드바 (주간 전용) & 신청 플로우

- 데스크탑: 주간 뷰에서만 우측 사이드바(`md:grid-cols-[minmax(0,1fr)_380px]` 기존 레이아웃 재사용,
  sticky). 구성은 기존 패널 콘텐츠에서 **일간/주간 토글만 제거**하고 유지:
  스텝 인디케이터 → 다크 요약 카드 → 예약 현황 카드(운영행 분할 타임라인) → 시간 선택 리스트
  (운영 안내 박스 포함) → sticky 선택 요약 + "예약 신청" CTA.
- 신청 스텝(slots→form→success)은 기존 그대로 사이드바 안에서 진행(BookingForm·BookingSuccess
  재사용, 문구·타임라인 무변경).
- **모바일: 바텀시트 제거.** 본문이 동일하게 월↔주 전환하고, 주간 뷰에서 그리드 아래에 사이드바
  콘텐츠가 세로 스택(그리드 → 요약 → 현황 → 리스트 → sticky CTA). `useIsMobileViewport` 게이트·
  Sheet 관련 코드는 사용처가 사라지면 정리(이중 마운트 문제 자체가 소멸).
- BookingPanel 의 `view`/`onChangeView` prop·PanelView 타입·내부 tablist 제거(그리드는 본문 소관).

## 6. 유지되는 것 (무변경 계약)

- 롤링 창 게이팅 전부: 창 밖 토스트·기간 외 셀·딥링크 정리 이펙트·월 이동 캡(당월⇄익월).
- 캘린더 칩(현재/다음 예약 가능)·오픈 마커·히트맵·오늘 도트.
- 토글 규칙(재탭=그 슬롯부터 해제)·409 처리·선택 무효 정리·submittedAt 캡처.
- 다크 요약·현황 카드(운영행 분할)·운영 안내 박스·슬롯 리스트(흰 바탕)·문구 정책 전부.
- 홈(전체 보기) 뷰·콘텍스트 바·MyBookingsChip·오늘 이용 현황·이용 안내.

## 7. Out of Scope

- 일간(Day) 뷰 — 사용자 지시로 [월][주] 2뷰만. 슬롯 리스트는 사이드바 역할로 존속.
- 목업 F4(별도 신청 확인 페이지)·F5(별도 완료 페이지) — 스텝은 사이드바 내 유지.
- 목업 FacSelectPanel 의 이용 시간(duration) 칩 — 슬롯 탭 방식과 중복.
- 주간 그리드 셀에 동아리명 표기(공간 제약 — "대기" 라벨만, 이름은 사이드바).
- 백엔드 변경 없음.

## 8. 주간 그리드 색상 정책 — 예약 블록화 + 파스텔 팔레트 (8차 요구, 2026-07-17)

예약이 많아지면 상태색만으로는 블록이 전부 같아 보인다. 역할을 분리한다:
**상태는 고정색(즉시 인지), 확정 예약 블록만 파스텔 팔레트로 구분.** Google/Notion Calendar·
에브리타임처럼 블록은 강조되되 화면이 화려해지지 않게 — Cream/Sage/Ink 시스템 유지.

### 8.1 예약 블록화 (그리드 렌더 단위 변경)

주간 컬럼을 슬롯(1시간) 셀 나열에서 **예약 건 블록**으로 바꾼다 — `dayOverviewTimeline`(운영행
분할 포함)을 컬럼 렌더에 재사용:

- BLOCKED(확정) 연속 구간 = 병합 블록 1개(rowSpan). PENDING 연속 구간 = 병합 블록.
  AVAILABLE·PAST 는 기존처럼 1시간 셀.
- **운영 구간은 블록이 아니다(2026-07-17 정정)** — 운영시간은 "예약 가능한 시간"이므로 그리드에서
  탭 선택이 가능해야 한다(§6 운영행 정책·주간=시간 선택의 장). 운영 노트 구간에 속한 AVAILABLE
  셀은 **sky 상태색의 선택 가능 셀**로 렌더한다(sage 대신 sky 계열 — 상태색 역할은 유지, 동작은
  일반 가용 셀과 동일: 탭 선택·토글·선택 시 ink+✓). 운영 단체명·시간은 셀에 넣지 않는다 —
  사이드바 현황 카드·운영 안내 박스가 담당.
- **PC 블록 내용**(확정·대기만): 동아리명 Bold + 시간 범위 소형 secondary(`▌ 비호응원단 /
  09:00~11:00`). 좌측 3~4px accent border(같은 계열 진한 톤). PENDING 은 비노출 정책대로
  "승인 대기"만.
- 블록도 button(접근성 — aria-label "요일 N일 HH:MM~HH:MM 라벨 상태"). PC에서 확정/대기 블록은
  비인터랙티브(disabled), 모바일에서는 §9.3 시트 트리거(확정·대기만 — 운영 셀은 시트 없음).

### 8.2 색상 매핑

| 대상 | 색(고정) |
|---|---|
| 예약 가능 셀 | sage 계열(현행 sage-mist/sage-soft) — 불변 |
| 운영시간 셀(선택 가능) | **Soft Blue = 기존 sky 토큰 계열**(bg sky-100 급·border sky-200 급) |
| 승인 대기 블록 | Amber(현행 warm 계열) — 불변 |
| 선택한 시간 | Ink(현행 ink+✓) — 불변 |
| 이용 불가/지난 | Gray(현행 graysoft 계열) — 불변 |
| **확정 예약 블록** | **파스텔 팔레트 순환(아래)** |

### 8.3 파스텔 팔레트 (tailwind 토큰 신설)

- `tailwind.config.ts`에 `pastel` 스케일 신설 — **6색: mint·lemon·coral·lavender·beige·rose**.
  각 색은 { bg(저채도 파스텔), border(같은 계열 한 단계 진함), accent(좌측 보더용 진한 톤) } 3단.
  sky 는 운영시간 고정색과의 충돌을 피해 팔레트에서 **제외**(사용자 예시 조정 — 보고 명시).
  lemon 은 warm(대기)과 혼동되지 않게 채도·명도를 낮게(accent 로 구분력 확보).
- **배정 규칙**: 동아리 영구 고정이 아니라 **현재 주간 화면에서 확정 블록 라벨(동아리명)의 첫 등장
  순서**로 팔레트를 순환 배정 — 같은 화면에서 같은 동아리는 같은 색(예시의 블록 단위 순환을 라벨
  단위로 조정: 한 동아리가 한 화면에서 두 색이 되는 혼란 방지). 순수 함수
  (`pastelIndexByLabel(labels)` 류)로 lib 에 두고 테스트.

## 9. 모바일 주간 압축 레이아웃 (8차 요구, 2026-07-17)

모바일에서 가로 스크롤 제거 — "한눈에 보기"와 "자세히 보기"를 분리한다. **PC(≥sm) 무변경.**

### 9.1 7일 한 화면

- 모바일(<sm)에서 `min-w`·가로 스크롤 제거, 시간열 축소(`w-8`, HH만), 7컬럼 균등(`table-fixed`).
- 행 높이 20~30% 축소: 셀 h-9(36px) → **h-6~7(24~28px)**.

### 9.2 블록 최소 표현 (모바일)

- 확정 블록: 파스텔 배경 + **1~2글자 약칭**(라벨 앞 2자, 예: "비호") 또는 공간 부족 시 색만.
  시간·풀네임은 숨김. 대기 블록: "대기" 1줄 또는 amber 색만. 운영 셀: sky 색만(약칭 없음).
- 선택일 강조: **컬럼 프레임 제거, 요일 헤더만**(sage 배경 또는 ink 밑줄 — 기존 ink 원형 유지 허용).
  PC 는 컬럼 프레임 유지.

### 9.3 블록 탭 → Bottom Sheet (모바일)

- 확정/대기 블록 탭 시 기존 Sheet(ui/sheet) 재사용해 상세 표시: 라벨(동아리명 또는
  "승인 대기") · 시간 범위 · 상태 배지(예약됨/승인 대기). SheetTitle+sr-only Description(접근성 전례). AVAILABLE 셀 탭은 모바일에서도 시트가 아니라
  기존 선택 동작.
- PC 에서는 시트 미사용(블록 비인터랙티브).

### 9.4 8~9차 Out of Scope

- "내 예약" 상태색(Ink) — 공개 가용성 API 에 내 예약 식별자가 없어 백엔드 확장 필요(후속 후보).
  선택한 시간의 Ink 표현이 현행 역할을 담당.
- 동아리별 영구 색 고정(100+ 동아리 서비스 특성상 부적합 — 사용자 판단 동일).
- 월간 캘린더·사이드바·현황 카드 색 변경 없음(주간 그리드 한정).
