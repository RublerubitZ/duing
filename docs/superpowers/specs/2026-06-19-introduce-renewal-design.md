# `/introduce` 전면 리뉴얼 — 설계

> 작성일: 2026-06-19 · 브랜치: `feat/introduce-renewal`

## 목표

방문자가 처음 접했을 때 **두잉이 무엇인지 · 어떤 문제를 해결하는지 · 왜 기존 방식보다 편한지 · 어떤 기능을 제공하는지**를 자연스럽게 이해하고 가입 또는 동아리 등록으로 이어지도록, 소개 페이지를 Apple 공식 홈 수준의 깔끔함·몰입감으로 개편한다.

무드 레퍼런스: Apple · Linear · Notion · Stripe. 키워드: 미니멀 · 프리미엄 · 신뢰감 · 여백 중심 · 부드러운 애니메이션 · 과하지 않은 인터랙션 · Sage Green 기반 브랜드 컬러.

## 핵심 원칙 (디자인 시스템 우선)

`frontend/DESIGN.md` 가 SoT 다. 충돌하는 외부 요구는 DESIGN.md 를 따른다.

- **라이트 고정** — 다크모드 코드 넣지 않음 (DESIGN.md 명시).
- **디자인 토큰 위로 재구축** — 현재 페이지는 off-system 하드코딩(`#3e5b34`/`#f3efe4`). ink `#1F4A36` · sage · cream `#F6F3EC` 토큰 + `.btn`/`.pill`/`.card` + GmarketSans 헤딩(h1~h4 자동) + JetBrains Mono 아이브로우 + 잉크틴트 섀도(`shadow-1~3`) + Sparkle 장식으로 옮긴다.
- **레이아웃 공식** — `max-w-layout`(1280) 중앙 + `px-4 sm:px-6 md:px-10`, 모바일 퍼스트(기본=세로 스택, `md:`=다컬럼), 수직 리듬은 비대칭.
- **실제 구현 기능만 홍보** — 존재하지 않는 기능 임의 추가·허위 소개 금지.

## 실제 기능 (코드 검증 결과, 홍보 대상)

- **부원**: 동아리 탐색·검색·필터(`/clubs`), 상세, 찜(`/me/favorites`), 지원서 작성·**자동 임시저장**(drafts), 지원 현황(`/me/applications`), 모집 캘린더(`/calendar`), 알림(`/notifications`, 마감·면접), 회비 납부 내역(`/me/fees`).
- **운영진**: 모집공고 생성/수정, 지원자 관리·필터·**일괄 상태 변경**, 면접 라운드(가능시간 수합→**자동 일정배정**→확정·재알림), 모집 통계(요약·일일·**펀넬**), 회비(정책·청구·납부 + **은행 거래 자동매칭**·금전출납부), 공지·일정·사진, 멤버 관리(역할·강퇴·**회장 인계**).
- **인증**: 이메일 + 이메일 인증(학생증 전용 아님). → 기존 "학생증 이메일 30초" 카피 정정.

## 모션 전략 (애플식, 은은)

- 섹션 등장: `@/components/motion/FadeIn` 재사용 (opacity + translateY, `whileInView` once, reduced-motion 안전).
- Stagger: 카드 그리드는 `FadeIn` 의 `delay` 점증(0.06s 간격) 또는 경량 Stagger 헬퍼로 요소별 시차 등장.
- Parallax: Hero 비주얼에 `useScroll`+`useTransform` 로 살짝 확대/축소 + 미세 이동(client 래퍼). 과하지 않게.
- easing 은 두잉 `cubic-bezier(.2,.7,.2,1)` 통일. 전역 `MotionConfig reducedMotion="user"` 존중.
- **금지**: 과도한 bounce · 현란한 회전 · particle · 불필요한 카운트업 (요구사항 + DESIGN.md Motion 원칙).

## 섹션 구성 (위 → 아래)

1. **Hero** — "동아리 운영, 이제 두잉으로." / 서브: 모집·공지·회비·멤버 관리까지 한 곳에서. CTA: `동아리 둘러보기`(`/clubs`) · `동아리 등록`(`/signup`). 비주얼: rotate 콜라주 카드 스택(모집/회비/공지/대시보드) + 스크롤 패럴랙스. 운영진 시선 우선, CTA 로 부원 동선 병행.
2. **문제 제기** — 기존 방식(카톡 공지·엑셀 회비·구글폼 지원서·흩어진 자료) → 문제(정보 분산·운영진 부담·신입 관리 어려움·회비 누락). 카드 stagger 등장.
3. **두잉이 해결합니다** — 6카드 그리드: 모집 관리 · 공지사항 · 회비 관리 · 멤버/권한 관리 · 알림 · 동아리 프로필. 실제 구현 기능만.
4. **실제 기능 (좌우 교차, Apple product-page)** — 목업과 함께 4블록:
   - ① 탐색·지원 — 카테고리 필터 + 키워드 검색, 지원서 자동 임시저장
   - ② 면접 운영 — 가능시간 수합 → 자동 일정배정 → 확정 (신규)
   - ③ 회비 — 정책·청구·납부 + 은행 거래 자동매칭·금전출납부 (신규)
   - ④ 운영 대시보드·통계 — 지원자 테이블·일괄 처리·펀넬
5. **두 개의 시선** — 한 섹션에 운영진 / 부원 2블록. 운영진: 지원자·공지·회비 발급·멤버/권한 ("운영에 쓰는 시간은 줄이고, 활동에 집중해요"). 부원: 캘린더·지원 현황·공지·회비 내역·알림.
6. **FAQ** — 네이티브 `<details>` 아코디언(접근성). 누구나 사용?/대구대 전용?/회비 기능 동작?/비용? — 학생증 부정확 문구 정정.
7. **최종 CTA** — "동아리 운영을 더 쉽고 체계적으로." / `지금 시작하기`(`/signup`) · `동아리 둘러보기`(`/clubs`). 브랜드 컬러 띠(다크 띠는 페이지당 1회 규칙 준수) + 푸터.

## 재사용 / 정리

- 재사용: `FadeIn`, `.btn`/`.pill`/`.card`, `.bg-grid`, `@/components/duing/Sparkle`·`Icon`, `HomeNav`, 디자인 토큰.
- 목업: 토큰 기반 재작성 + 면접/회비 목업 신규.
- 죽은 컴포넌트 삭제: `Audiences`(구)·`HowItWorks`·`Testimonials`·`Solution`(구)·`PromoNav`·`FeatureSection`(→ FadeIn 으로 대체). 단, 새 구성에서 동일 역할로 재작성하는 파일은 교체.

## 기술 요구사항

- Next.js App Router 준수 — `page.tsx` 는 서버 컴포넌트, 모션은 `'use client'` 래퍼로 분리(서버 컴포넌트 우선).
- TypeScript — 타입 선언 `type`, `any`/`as` 금지.
- 반응형·모바일 최적화 — `px-4 sm:px-6 md:px-10`, 터치 타깃 ≥44px, `min-h-dvh`.
- 접근성 — reduced-motion 존중, 시맨틱 헤딩 위계, `<details>` FAQ, CTA 링크 명확.

## Out of Scope

- 다크모드 대응 (DESIGN.md 라이트 고정 — 금지).
- 실제 앱 스크린샷 캡처 (손수 만든 토큰 기반 목업으로 대체).
- 숫자/지표(Stats) 섹션 — 실데이터 없음, 허위·placeholder 0 노출 금지 → 섹션 삭제.
- 백엔드 실데이터 연동 (정적 홍보 페이지 유지).
- `/introduce` 외 라우트·전역 컴포넌트 변경.
- 새 디자인 토큰 추가 (기존 토큰 어휘 내에서만).
